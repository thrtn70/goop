# Bundled typefaces

Unmodified WOFF2 files from Fontsource variable packages version 5.3.0. Bricolage Grotesque retains optical sizing (12–96) and weights 400–700; Figtree retains weights 300–600. CSS aliases match the existing application font names. All supplied normal-script subsets are included. The application loads these fonts locally and makes no startup font request.

Both families use the SIL Open Font License 1.1; full copyright and license texts are retained in the adjacent `*-OFL.txt` files. `provenance.json` records exact package tarballs, upstream metadata, archive hashes and unchanged asset hashes. No runtime package dependency is required.
